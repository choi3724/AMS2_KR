# 런처 업데이트 — Open Beta 0.85

일반·VR 런처 모두 설치된 게임 빌드에 맞는 호환성 규칙을 선택한다.
지원 빌드는 24132163과 25271800이다. 이전 게임에서 설치한 뒤 지원되는 새 게임으로
업데이트되면 필요한 파일을 재적용하고 제거용 원본도 새 게임 기준으로 갱신한다.
검증되지 않은 파일을 빌드 번호만으로 허용하지 않는다.

업데이트 확인·5초 카운트다운·Pretendard·제작자 표시는 유지하며 버전은 0.85이다.
새 패치 설치 및 파일 검증 성공 후 “업데이트가 완료되었습니다. 게임을 실행합니다.”를
약 2초 표시한 뒤 선택했던 일반·VR 모드로 실행한다.

배포 ZIP은 AMS2.0.85.zip, 내부 설치 파일은 AMS2 한국어 패치 오픈베타 0.85.exe다.
기존 0.82/0.83 업데이터의 버전 비교·설치 규약을 유지한다.
자동 검사와 실제 게임 확인의 차이는 VALIDATION.md에 기록한다.

HUD 베타 설명의 한국어 직접 문자열 교체를 두 지원 빌드의 재적용에 보존한다.
