# AMS2 한국어 패치 완전 제거 도구

설치 실패, 불완전한 제거, 손상된 설치 기록 때문에 일반 복구가 막힐 때 사용합니다.
설치 기록이나 현재 파일 내용에 의존하지 않고, 도구에 포함된 검증된 순정 파일로 복구합니다.

1. 게임과 한글 런처, 한글패치 설치 프로그램을 종료합니다.
2. `AMS2 한국어 패치 완전 제거.exe`를 실행하고 관리자 권한 요청을 허용합니다.
3. 해당 PC의 `Automobilista 2` 게임 폴더를 선택하고 **완전 제거 / 순정 복구**를 누릅니다.
4. 완료 후 **Steam 라이브러리에서 원본 게임**을 실행해 글씨가 정상적으로 보이는지 확인합니다.
5. 원본 게임이 정상인 것을 확인한 뒤 한글패치를 다시 설치합니다.

지원 범위는 한글패치 0.7~0.82, 게임 빌드 24132163입니다.
순정 파일 278개를 복구·검증합니다. 기존 복구 대상 100개에 기본 BFONT 176개와
기본 폰트 관련 BOOTFLOW/FONTKOREAN 아카이브 2개를 추가했습니다.
패치 추가 파일 367개와 별도로 풀린 기본 폰트 이미지 32개를 합해 399개 경로를 제거·검증합니다.
이 32개는 고정된 폰트 경로 목록이며, GUI 폴더의 임의 파일을 일괄 삭제하지 않습니다.
바탕화면·시작 메뉴·작업 표시줄 및 설치 기록의 바로가기는 실제 연결 대상이
선택한 게임의 일반/VR 한글 런처인지 확인한 다음 백업·제거합니다. 이름을 바꾼 바로가기도 확인합니다.
대상 경로에 다른 내용이 있더라도 백업 후 교체·제거하므로, 일반 설치 프로그램의 제거 기능과 다릅니다.
세이브, 리플레이, 다른 경로의 모드, 게임 실행 파일은 복구 대상에 포함되지 않습니다.
같은 기본 폰트 파일과 폰트 이미지를 사용하는 다른 모드의 글꼴 변경은 순정으로 돌아갑니다.
안전 백업과 기존 원본 백업은 남기므로, 게임에 영향을 주는 패치 제거와 백업 삭제는 구분됩니다.
다른 게임 빌드에는 이전 순정 파일을 덮어쓰지 않고 중단합니다.

현재 파일과 이전 설치 기록은 게임 폴더의 `Backup/AMS2-Korean-StockRestore`에 보관됩니다.
`before.tsv`는 백업 번호·원래 파일 경로·해시·파일 속성의 대응표이며, `events.log`에는 작업 결과가 남습니다.
기존 원본 백업은 보존하며, 활성 설치 기록은 별도 백업한 다음 제거해 재설치를 막지 않도록 합니다.
복구 도중 오류가 나면 이번 작업에서 바꾼 파일을 작업 전 상태로 되돌리고 결과를 표시합니다.

## 개발 검증

외부 출력 폴더는 `build/full-uninstall`입니다. 원본 해시 대조 및 빌드:

```text
python -B tools/repository/Build-StockRestore.py
python -B tools/repository/Test-StockRestore.py
```

임시 게임 폴더에서 손상·누락된 파일, 손상된 설치 기록, 반복 실행, 읽기 전용 파일,
복구 도중 실패 시 원복, 잠긴 파일, 손상된 내장 파일, 다른 게임 빌드의 거부를 검사합니다.
실제 배포본 0.8 → 0.81 → 0.82의 파일 설치와 독립 순정 복구도 검사합니다.
바로가기 연결 대상 확인, 무관한 바로가기 보존, 바로가기 제거 후 실패 시 원복,
완전 제거 후 0.82 재설치와 재제거까지 확인합니다.
이는 파일 단위 검증이며, 문제가 발생한 사용자 PC에서의 게임 화면 확인은 별도로 필요합니다.

2026-09-09 이전 순정 복구 도구에 대한 사용자 확인: 복구 후 영문 출력, 재설치와 실행은 정상이나
폰트가 패치 폰트처럼 보인다는 보고가 있었습니다. 기존 도구는 기본 폰트 및 바로가기를 직접 처리하지 않았습니다.
새 완전 제거 도구의 원본 278개는 Steam 빌드 24132163 공식 파일 목록의 크기와 SHA-1에 일치하며,
제거 대상 399개 경로는 해당 공식 파일 목록에 없음을 빌드 시 검증합니다.
새 도구를 사용한 해당 PC의 순정 폰트 외관 확인은 아직 대기 중입니다.

## 기본 폰트 진단

`AMS2 기본 폰트 진단.exe`에서 게임 폴더를 선택하고 **폰트 진단 저장**을 누릅니다.
현재 한글패치를 유지한 채 기본 폰트와 기본 폰트 관련 아카이브를 공식 원본 해시와 비교합니다.
별도로 풀린 글자 이미지의 해시도 수집하지만, 아카이브 내부 이미지와의 일치 여부는 이 도구에서 판정하지 않습니다.
진단 전용 실행파일에는 복구 버튼과 순정 복구 데이터가 없으며, 게임 파일을 변경하지 않습니다.
생성한 ZIP에는 파일 상태와 마지막 순정 복구 기록이 들어 있습니다. 다른 게임 빌드 또는 다른 모드의 변경도
원본과의 차이로 보고될 수 있으므로, 차이가 있다는 사실만으로 한글패치 잔여 파일이라고 판단하지 않습니다.

## 일반 설치 프로그램의 다음 배포에 포함할 수정

- 중단된 업데이트에 남은 이전 패치 파일을 수동 변경으로 잘못 판단하던 복구 오류 수정.
- 복구 대상 전체를 먼저 확인하고, 일부만 제거된 상태에서도 복구 재시도 지원.
- 설치·복구 실패 로그 보존 및 최근 작업 로그와 ERS 계기판 파일 상태를 진단 ZIP에 포함.
- 긴 파일명 뒤에 임시 이름을 덧붙이던 공통 파일 저장 방식을 수정하고, 실패 시 임시 파일 정리.
- 업데이트 완료 후 `업데이트가 완료되었습니다. 게임을 실행합니다.` 안내는 기존 반영 대기 수정 유지.

이 작업으로 기존 0.82 배포 파일을 교체하거나 새 릴리즈를 게시하지 않습니다.
