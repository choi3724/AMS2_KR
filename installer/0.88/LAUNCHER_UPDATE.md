# 런처 업데이트 — Open Beta 0.88

일반 런처와 VR 런처는 실행 전 동일한 업데이트 대응 검사를 한 번 수행한다. 새 빌드 번호만으로 차단하지 않으며, 현재 파일에 필요한 한글 변경을 안전하게 만들 수 있으면 자동 재적용한 뒤 안내창을 표시하고 실행한다.

핵심 한글 자산이 유효한 상태에서 부가 HUD 항목만 적용할 수 없으면 해당 파일과 이유를 안내하고 한글 모드 실행을 계속한다. 필수 자산 누락·손상, 구조적 비호환, 복구되지 않은 부분 적용은 실행을 중단한다.

실행 인수:

- 일반: `-applaunch 1066890 -novr -lang=Korean -looseloadtext`
- VR: `-applaunch 1066890 -forcevr -lang=Korean -looseloadtext`

Steam 실행 요청 성공은 실제 게임 내 한글 표출 확인과 구분해 표시한다.
