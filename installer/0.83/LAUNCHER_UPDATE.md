# 런처 업데이트 — Open Beta 0.83

일반·VR 런처는 약 5초간 업데이트를 확인하고 카운트다운 후 실행한다. 새 버전이 있으면
현재 버전 실행 또는 업데이트를 선택하도록 기다린다. 오프라인에서도 현재 설치본을 사용할 수 있다.
Pretendard와 `한글 패치 제작자 : ENGIceBlasT` 표시는 유지한다.

게임 실행 직전 공통 `GameLauncher`에서 설치 기록과 변경된 게임 파일을 검사한다.
호환되는 공식 메뉴 파일은 원본을 백업하고 한글 폰트 연결을 다시 적용한다. 알 수 없는
폰트·아카이브·번역 인덱스 변경은 실행을 중단하고 안내한다. 모든 향후 업데이트의 자동 지원을 뜻하지 않는다.
게임 업데이트 후 제거할 때도 최신 원본으로 복구하도록 백업 기준을 갱신한다.

패치 업데이트의 설치 및 파일 검증이 성공하면 `업데이트가 완료되었습니다. 게임을 실행합니다.`를
약 2초 표시한 뒤 같은 일반·VR 모드로 실행한다. 실패 시 완료 안내나 게임 실행으로 넘어가지 않는다.

GitHub 자산 이름 `AMS2.0.83.zip`, 내부 설치 파일 `AMS2 한국어 패치 오픈베타 0.83.exe`,
버전 `0.83.0.0`, 업데이트 규약 `AMS2 Korean Patch Launcher Update Protocol 1`을 사용한다.
다운로드의 크기·SHA-256 및 압축 경로를 검증한다. 기존 0.81/0.82 업데이터의 이름 규약을 유지한다.

자동 검사와 실제 확인의 범위는 [VALIDATION.md](VALIDATION.md)에 기록했다.
실제 VR 헤드셋과 배포된 새 ZIP을 이용한 전체 자동 업데이트 경로는 미검증이다.
