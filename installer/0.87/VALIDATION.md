# Open Beta 0.87 validation

검증 범위:

- 검증 이력이 있는 빌드와 미검증 빌드의 최초 설치·재적용·제거
- 빌드 번호만 변경된 경우와 Steam depot manifest가 없는 경우
- 여러 파일 변경, 패치 상태 혼재, 반복 실행의 멱등성
- 부가 HUD 적용 실패 시 핵심 한글 실행 가능 상태 유지
- 필수 BGUI 여러 개의 구조 실패 수집 및 무변경 보장
- Content Manager 재생성, 무관한 모드 변경 보존, 실제 충돌 판정
- 쓰기 실패 롤백과 강제 중단 후 다음 실행 복구
- 일반·VR Steam 실행 인수 및 업데이트 런처 규약
- 기존 번역·도움말·ERS·폰트·HUD 자산 회귀 게이트

위 항목은 검증 대상이다. 이번 0.87의 실제 결과와 구버전 인계 검증은 `docs/COMMON_UPGRADE_0.87.md`에 기록한다. 실제 게임 화면의 한글 표출과 VR 확인은 자동 복사본 검증과 구분한다. 원본 백업이 없을 때는 업그레이드 직전 상태로 복원하며, 순정 게임으로의 완전 복원을 검증했다고 주장하지 않는다.
