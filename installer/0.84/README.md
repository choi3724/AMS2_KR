# Open Beta 0.84

CM generated bootfiles are checked and Korean overlay reapplied before normal/VR launch
and before upgrades of an installed patch. Only reviewed native file contents owned
exclusively by __bootfiles_generated are supported; unknown edits remain blocked.

CM must be disabled before Korean uninstall. Arbitrary shared mod edits and all possible
CM versions are not supported. The ordinary launch candidate was confirmed by the user;
VR visual confirmation remains outstanding.

Build with Version 0.84 and reviewed cm-overlays.json.gz in the compatibility data root.
See ../../docs/CONTENT_MANAGER_COMPATIBILITY.md for provenance and test scope.
