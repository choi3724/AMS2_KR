# Closed Beta 0.6.5 검증

Closed Beta 0.6.5는 현재 검증된 번역과 차량 위 이름 폰트 라우팅을 별도 기준점으로 동결한 배포본이다.

## 검증 결과

- 0.6.4 설치 상태 감지: PASS (`UPDATE_AVAILABLE`)
- 0.6.5 업데이트 설치: PASS (`UPDATED_EXACT`)
- 한국어 Main Menu 부팅: PASS
- 프로필 → Replay → 첫 번째 Replay → View Replay: PASS
- 차량 위 `ProfileName` Pretendard HUD 폰트 출력: PASS
- BFF CRC 오류: 0
- 제거 및 설치 전 상태 복구: PASS (`RESTORED_EXACT`)
- 일반 Steam 실행으로 영어 Main Menu 부팅: PASS
- 0.6.5 재설치: PASS (`INSTALLED_EXACT`)

`Pakfiles/IGPHASEHUD.bff`는 전체 배포하지 않는다. 설치 프로그램은 지원 원본에 대해 엔트리 288의 필요한 바이트만 패치하고 목표 SHA-256을 검증한다.
