# v0.6.6 회귀 대조 결과

결론은 **0.6.6에서 변경된 번역·AI 이름·추가 글리프가 현재 파일에서 원래 값으로 되돌아간 항목은 0건**이다.

- `game.tdb`의 0.6.6 변경 4건: 전부 유지
- `general.tdb`의 변경 29건과 추가 7건: 전부 유지
- `drivers.tdb`의 4,201개 한글 AI 표시명: 의미상 전부 유지
- 0.6.6에서 추가한 AI 이름용 한글 68자: 누락 0
- 0.6.6 변경 전 문구를 전체 BGUI에서 교차 검색한 결과, 사용자 화면용 미해결 fallback 0건

검색 후보 3건은 모두 사용자 문구가 아닌 기술 식별자였다.

- `USA`: `_USA_`, `STOCKUSA...`
- `Japan`: `JapaneseBootFlow`, `JP-antipiracy`
- `Rallycross`: `RallycrossResultsTable`, `RallycrossTabMenu`

## 확인된 실제 회귀와 수정

1. `셋업 제한`
   - TDB는 새 번역이었지만 `menu_mainmenu_1_6.bgui`에 옛 fallback `제한 셋업`이 남아 있었다.
   - v0.6.6 BGUI 기준 단 한 곳만 동일 길이로 바꿨고, 변경량은 8바이트다.

2. 0.6.6 폰트 시각 회귀
   - AI 이름 글리프를 추가하면서 기존 글리프 atlas까지 다시 생성된 것이 회색 배경·테두리 회귀의 원인이었다.
   - 기존 0.6.5 글리프 픽셀/metrics를 그대로 유지하고 0.6.6의 AI 음절 68자와 NBSP만 추가한 상태로 복원했다.

3. 차량 위 이름
   - 커스텀 `IGPHASEHUD.bff` route가 이름 깨짐을 만들었고, stock route에서는 정상 출력됨을 확인했다.
   - 현재 `IGPHASEHUD.bff`는 stock SHA `F967D1A322EB75AAD742CF21888D75DB0CA4CB407ACDEC72F14D32BD5351E7DA`다.

## 별도 남은 항목

싱글 레이스의 거리값 `6213`은 0.6.6 회귀가 아니다. 0.6.6 자체가 `거리(m) + 원시 미터값`을 명시적으로 사용했다. 이번의 `거리 6,213 미터` 요구는 새 formatter 작업이다.

현재 BGUI가 받는 속성은 `PreviewTrack_Length` 하나뿐이며, 포맷된 길이 속성은 BGUI와 실행 파일 문자열 목록에서 발견되지 않았다. 로딩 화면과 프로필 누적 거리는 서로 다른 킬로미터 formatter를 사용하므로 전역 TDB 치환으로 해결하면 다른 화면 단위가 깨진다.

따라서 이 항목은 EXE/DLL 변경이나 전역 단위 훼손 없이 적용 가능한 data-only 경로를 추가로 확인하기 전까지 `PENDING_FORMATTER_PATH`로 분리한다.
