# Content Manager 동시 사용 지원 — 실행 전 재적용 후보 구현

사용자 요구: Content Manager와 한글패치를 함께 사용해야 한다. 어느 한쪽을
제거하도록 안내하는 것을 최종 해결책으로 삼지 않는다. 현재 정상 게임 파일은
유지하고 별도 복사본에서 호환 처리를 검증한다. 이 문서는 지원 완료를 의미하지 않는다.

## 확인한 실행 대상

2026-09-15 시작 메뉴의 `AMS2 Content Manager`, `AMS2 CM`은 모두
`E:\ams2track\outputs\ams2-tools\AMS2CM\Launch-AMS2CM.ps1`을 가리킨다.
실제 실행 파일은 하위 `app/AMS2CM.GUI.exe`, 파일 버전은 0.3.0.0,
제품 버전은 `0.3.0+Branch.tags-v0.3.0.Sha.7058b9431a7b4943ef4d66a6be5de08292948c42`다.
사용자는 시작 메뉴의 1.0 프로그램을 지정했으므로 동일 프로그램인지 확인이 필요하다.
임의로 다른 버전의 설정이나 파일을 바꾸지 않는다.

## 확인한 충돌 방식

- 한글패치 설치·복구·실행은 같은 GameUpdateCompatibility 검사를 거친다.
- 해당 메뉴 `gui/menu_dialogbox_gamewide.bgui`는 0.83.3 관리 대상이다.
  생성 파일로 기록되며 패치 해시는 1461E0C761F6DBDFFAE9E2FE13E50952E31D37FAEA5729D478F58D47FCB46DA9다.
- CM 0.3 소스의 GeneratedBootfiles는 BOOTFLOW/PHYSICSPERSISTENT를 풀어
  loose 파일을 설치하고, 부트 아카이브도 교체/제거한다. 단순한 파일 일부 수정이 아니다.
- JsgmeFileInstaller는 기존 파일을 `.orig`로 이동하고 모드 파일을 설치한다.
  모드를 제거할 때는 `.orig`를 복원한다. 한글패치 후 모드를 설치했다면 이 백업에도
  한글패치 파일이 남을 수 있다.
- CM 0.3의 `ExcludedFromInstall`은 ManualInstallMod에서 적용한다.
  GeneratedBootfiles는 별도의 ExtractedMod 경로를 사용한다. 해당 설정에
  한글 파일을 추가하는 것만으로 공통 부트파일 충돌까지 해결된다고 보장할 수 없다.
- 최신 공개 소스에도 별도의 공통 부트파일 생성 및 백업 복원 경로가 있다.
  https://github.com/OpenSimTools/AMS2CM

## 구현·검증 요구사항

1. 실제 사용 버전의 부트파일 생성/모드 설치/모드 제거 전후 파일 목록과 바이트,
   `.orig`, CM 설치 기록을 복사본에서 확보한다.
2. 공유 파일별로 한글 변경 영역과 모드 변경 영역을 구분한다. 의미가 보존된
   변경만 허용하며, 전체 해시 불일치를 무조건 무시하는 우회는 추가하지 않는다.
3. 두 도구의 백업 순서를 함께 처리한다. 모드 제거로 구버전 한글패치가 되살아나거나,
   한글패치 제거로 모드가 지워지는 것을 방지해야 한다.
4. 다음 순서를 모두 검사한다: 모드→한글, 한글→모드, 모드 끄기/켜기,
   한글패치 업데이트, 모드 유지 중 한글패치 제거, 한글 제거 후 모드 제거,
   작업 중단/롤백, Steam 업데이트. 실제 일반·VR 게임 화면은 별도로 확인한다.
5. 수정 영역이 겹치거나 CM 버전을 식별할 수 없을 때에는 원인을 안내하고
   현재 파일을 보존한다. 범용 모드 호환이 검증됐다고 표시하지 않는다.

  임의의 추가 모드 변경을 합치는 범용 병합기는 아니다.
- 일반·VR 공통 `GameLauncher.Start`에서 매 실행마다 확인한다.
  이미 적용된 파일은 다시 쓰지 않는다. CM 백업, 설치 기록, 생성 시간을 보존한다.
- 쓰기 실패 시 롤백, 프로세스 중단 시 다음 실행에서 저널을 복구한다.
- 설치·제거 경로에는 새 동작을 연결하지 않았다. CM 백업에 한글이 남는 문제를
  고려한 제거 설계와 CM→한글 최초 설치 순서는 후속 검증이 필요하다.

## 0.84 릴리즈 반영

사용자가 일반 게임 실행 정상 동작을 확인하고 0.84 커밋·릴리즈를 요청했다.
최종 소스는 `installer/0.84`이다. 기존 설치 업그레이드에도 CM 재적용을 연결했다.
CM이 활성화된 경우 한글패치 제거는 파일 변경 전에 안내하고 중단한다.
CM 비활성화 후 제거하는 경로를 사용한다. CM 자체의 백업 내용을 수정하지 않는다.
VR 화면과 임의의 다른 모드가 같은 파일을 수정하는 경우는 검증 범위 밖이다.
