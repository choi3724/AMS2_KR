# 2026-09-09~10 한글패치 전반 점검

현재 배포본의 무결성과 설치·복구 경로를 점검하고, 사용자 요청에 따라 별도 완전 제거 도구를 만들었다.
점검과 자동 검사는 임시 게임 폴더에서 수행했으며 실제 설치된 게임은 수정하거나 실행하지 않았다.
커밋·태그·푸시·새 릴리즈 게시와 기존 배포 파일 교체는 하지 않았다.

## 배포 및 데이터

- GitHub 최신 릴리즈는 `v0.82`, 자산은 `AMS2.0.82.zip`, 64,480,474바이트다.
- GitHub 자산 digest와 로컬 배포 ZIP의 SHA-256은 다음 값으로 일치했다.

```text
af00158ecf5d1af3be6ba8e2800402330fc6b0ea8206bf23b676613a86ea900d
```

- ZIP 497개 파일의 압축 무결성을 확인했고, 설치 목록 465개 파일의 크기와 SHA-256이 일치했다.
- 번역 TDB 9개, 총 18,081개 키와 각 14개 언어 블록을 읽었다. 잘못된 UTF 인코딩이나 값 전체가 `**`인 한국어 항목은 없었다.
- 패치 BFONT 53개의 구조를 검사했다. 이 결과는 모든 화면의 실제 출력이 정상이라는 의미는 아니다.
- 세이프티 카 이름 3개는 모두 `세이프티 카`다. 리플레이 저장 안내와 하이라이트 도움말도 요청한 의미로 수정되어 있다.
- 기준 커밋은 `8421f83176b86a61c5c9bdfdd6a9f523992e0463`이며, 아래 복구·업데이트 소스 변경은 배포 대기 상태다.

## 완전 제거 도구

기존 순정 복구 도구는 원본 100개와 추가 파일 367개를 처리했으나 기본 폰트와 한글판 바로가기는 직접 정리하지 않았다.
새 도구는 원본 278개를 복구·해시 검증하고, 추가 폰트 이미지까지 399개 경로의 제거를 확인한다.
원본은 Steam 빌드 24132163의 공식 depot 파일 크기·SHA-1과 일치하며, 제거 대상은 공식 loose 파일 목록에 없다.

설치 기록이 없거나 손상되어도 내장 원본으로 복구한다. 선택한 게임의 일반/VR 한글 런처를 가리키는 바로가기는
연결 대상을 확인한 뒤 정리한다. 무관한 바로가기는 보존하며, 손상된 기록의 경로를 그대로 삭제 권한으로 사용하지 않는다.
현재 파일·기록·바로가기를 먼저 백업하고, 중간 실패 시 바꾼 내용을 작업 전 상태로 되돌린다.

세이브·리플레이·게임 실행 파일·다른 경로의 모드는 유지한다. 동일한 기본 폰트 경로의 다른 모드 변경은 순정으로 돌아간다.
안전 백업은 남긴다. 다른 게임 빌드는 이전 원본을 덮어쓰지 않도록 거부한다.

개발 및 사용 안내: [RECOVERY.md](../installer/0.82/RECOVERY.md).

## 후속 수정 대상

### 설정 도움말의 글자 4개

공통 UI 폰트 문자표에 `켤`, `끕`, `뀝`, `켬`이 없다. 해당 글자는 `game.tdb`의 설정 도움말 8개에 사용된다.
주행 보조, 기계적 고장, 자동 시동, 근접 차량 표시, 게임패드 진동, RPM/기어 표시, 열 왜곡, 주행 안정장치 설명이다.
문자표와 번역 데이터의 차이는 확인했으며, 실제 각 화면에서 어떻게 보이는지는 아직 확인하지 않았다.
다음 폰트 생성 시 최종 번역문 전체를 문자 목록에 반영하고 화면 검사를 해야 한다.

### 번역 치환 항목 13개

자동 토큰 순서 검사는 228개를 표시했지만, 문장 순서와 줄바꿈 차이를 모두 번역 오류로 취급하지 않았다.
토큰 종류·개수 차이 18개 중 일반 화살표·목록 기호·국가명 괄호 5개를 제외하면 다음 13개다.

| 파일 | 항목 | 차이 |
|---|---|---|
| general.tdb | LengthFormatInches, LengthFormatFeet | `[LENGTH]`가 `[길이]`로 번역됨 |
| career.tdb | NewsResults_nr02 | `[TEAM]` 누락 |
| career.tdb | NewsResults_nr05, NewsTimings_nt01, NewsTimings_nt05 | `[EVENTNAME]` 누락 |
| career.tdb | InboxInvitations_Invitation02 | 원문에 없는 `[TEAM]` 추가 |
| career.tdb | NewsDisqualified_nd04 | `[INCIDENT_LAPNUMBER]` 누락 |
| online.tdb | GROUPTEAMPVPNEEDEDMATCH, GROUPTEAMPVENEEDEDMATCH | `[NEEDED]/[MATCHED]` 누락 |
| online.tdb | MATCHINGEVENTMATCHEDNEE, MATCHINGSOLOMATCHEDNEED, MATCHINGTEAMMATCHEDNEED | `[MATCHED]/[NEEDED]` 누락 |

현재 데이터의 차이를 확인한 것이며, AMS2가 해당 레거시 키들을 실제로 모두 사용하는지는 별도 확인이 필요하다.
이 번역 및 폰트 수정은 이번 제거 도구에 섞어 적용하지 않았으며, 배포본에도 아직 반영되지 않았다.

## 사용자 화면 검사 대기

- 새 완전 제거 도구 실행 후 Steam 원본 실행에서 영문과 순정 폰트 외관 확인.

빌드 산출물·사용자 진단 ZIP·원본 게임 파일은 Git 저장소에 포함하지 않는다.

공유 파일은 외부 `recovery/AMS2 한국어 패치 완전 제거.exe` 및 같은 이름의 ZIP이며,
`build/full-uninstall/delivery.json`에 실행파일·ZIP 해시와 빌드 소스 해시를 기록한다.
