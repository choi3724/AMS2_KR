# AMS2 한국어 패치 오픈베타 0.83

Automobilista 2 V1.6.9.95 업데이트 이후 한글 메뉴가 `*`로 표시되는 문제에 대응했습니다.

- 최신 게임 버전에 맞춰 메뉴, 이름 표시와 ERS 계기판의 한글 표시를 수정했습니다.
- 일반·VR 한글 런처에서 게임 파일 변경을 확인하고, 호환되는 메뉴는 원본을 백업한 뒤 한글 연결을 자동으로 다시 적용합니다.
- 자동으로 검증할 수 없는 게임 업데이트는 실행 전에 안내합니다. 모든 향후 업데이트가 자동으로 지원되는 것은 아닙니다.
- 업데이트 완료 후 “업데이트가 완료되었습니다. 게임을 실행합니다.” 안내를 표시합니다.
- 설치 실패 후 복구 처리와 진단 기록을 개선했습니다.

기존 사용자는 0.83 압축파일을 새 폴더에 풀고 설치를 진행해주세요. 설치 후에는 한글판 바로가기 또는 한글 런처로 실행해주세요.

V1.6.9.95에서 실제 게임 실행과 메인 메뉴 한글 출력을 확인했습니다.

멀티플레이 리플레이 저장 안내는 실제 게임에서 아직 확인하지 못했습니다. 기존 리플레이의 세이프티 카 이름과 타이머 잘림, VR 기기의 실제 실행 확인도 남아 있습니다.
