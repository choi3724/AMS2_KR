# AMS2 한국어 패치 Closed Beta 0.6.3

## 변경 사항

- 메뉴·레이스 설정·피트 전략 번역과 용어 32건을 수정했습니다.
- 레이스 요약의 `건조/우천 실력`, `제한 셋업` 표시를 보완했습니다.
- 피트 전략 편집의 서스펜션·브레이크·수리 선택 문구를 자연스럽게 수정했습니다.
- 기존보다 넓던 영문·숫자 폰트 폭을 줄여 긴 장치명, 해상도, 날짜, 랩타임과 HUD 숫자 잘림을 개선했습니다.
- 한글 글리프 메트릭은 변경하지 않았습니다.
- 설치된 이전 패치 버전을 감지해 업데이트 상태를 안내합니다.
- GitHub 새 버전 확인 버튼을 추가했습니다. 조회 실패는 설치를 막지 않습니다.

## 실행

설치 후 Steam의 기본 실행 버튼이 아니라 설치 과정에서 만든 `오모빌2 한글판` 또는 `오모빌2 한글판 VR모드` 바로가기를 사용하십시오.
