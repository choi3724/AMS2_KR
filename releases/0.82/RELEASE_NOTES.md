# AMS2 한국어 패치 오픈베타 0.82

한글 패치 제작자 : ENGIceBlasT

## 수정 사항

- 포뮬러 하이브리드 Gen1 계기판의 ERS 모드명이 `**`로 표시되던 문제를 수정했습니다.
- ERS 모드 변경 알림과 같은 표시를 사용하는 일부 포뮬러·SC63·Porsche 963 계기판에도 한글 표시 수정을 반영했습니다.
- 수정 파일을 인스톨러의 설치·업데이트·제거/복구 기능에 포함했습니다.
- 일반·VR 런처와 인스톨러의 버전을 0.82로 변경했습니다.

## 설치 및 업데이트

압축을 모두 푼 뒤 **AMS2 한국어 패치 오픈베타 0.82.exe**를 실행해주세요. 설치 후에는 한글판 바로가기를 이용해주세요.

0.81 사용자는 한글 런처의 업데이트 안내 또는 새 설치 파일로 업데이트할 수 있습니다. 0.8 이하 사용자는 새 압축파일을 직접 내려받아 설치해주세요.

게임 파일이 지원 버전과 다르면 설치가 중단될 수 있습니다. 이 경우 최신 패치 안내를 확인해주세요.

## 확인 중인 사항

- 포뮬러 하이브리드 Gen1의 평상시 ERS `균형` 표시는 실제 게임에서 정상 확인했습니다. 다른 모드, 변경 알림, 다른 차량은 추가 확인이 필요합니다.
- 멀티플레이 리플레이 저장 안내는 문구 수정을 반영했으나 실제 표시 확인은 아직 진행하지 못했습니다.
- 리플레이 시간 표시가 일부 잘리는 현상은 아직 해결되지 않았습니다.
- VR 헤드셋 실행 및 자동 업데이트 후 게임 재실행까지의 전체 과정은 추가 확인이 필요합니다.

이 패치는 비공식 한국어 패치입니다. 문제가 발생하면 차량명과 발생 화면을 함께 알려주세요.
