# AMS2 한국어 패치 CB 0.8

## 변경 사항

- 게임 실행 전 최신 한글패치를 확인하고, 새 버전이 있으면 업데이트 여부를 선택할 수 있습니다.
- 약 5초 카운트다운 후 게임을 시작하며, 바로 실행할 수도 있습니다.
- 매번 나타나던 Steam 실행 옵션 확인 단계를 줄였습니다.
- 일반·VR 런처 디자인을 개선하고, 제작자·버전 정보와 한글 글꼴의 가독성을 높였습니다.
- 리플레이 저장 안내와 관련 도움말을 수정했습니다.
- 세이프티 카 이름 표기를 `세이프티 카`로 통일했습니다.
- 업데이트 후 제거·복구 시 이전 원본 백업을 더 정확하게 이어받도록 개선했습니다.
- 별도 긴급 제거 도구를 제외하고, 인스톨러의 제거·복구 기능으로 통일했습니다.

## 참고 사항

- 리플레이 저장 안내는 멀티플레이에서 실제 화면 확인이 남아 있습니다.
- 이전에 저장한 리플레이에는 기존 세이프티 카 이름이 남을 수 있습니다.
- 리플레이 시간 표시 잘림은 아직 해결되지 않았습니다.
- VR 헤드셋에서의 최종 실행 확인은 남아 있습니다.

## 설치

ZIP 파일을 모두 압축 해제한 뒤 `AMS2 한국어 패치 CB 0.8.exe`를 실행하여 설치·업데이트합니다.
이후 일반 또는 VR 한글판 바로가기로 게임을 실행하세요.

패치를 제거하려면 같은 인스톨러에서 `제거 / 복구`를 선택하세요.
