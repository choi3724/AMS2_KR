# AMS2 한국어 패치 Closed Beta 0.6.6

0.6.6은 0.6.5를 기준으로 서킷 정보·거리·플레이어 통계와 싱글플레이 순정 AI 이름의 한국어 표시를 보완한 버전입니다.

## 변경 사항

- 서킷 국가명 및 코스 타입의 한국어 표시 보완
- 싱글 레이스 서킷 상세는 `거리(m)`와 원시 미터값으로 표시
- 로딩 화면과 플레이어 선호도의 누적 거리는 `킬로미터`로 표시
- 플레이어 선호도의 `타임`을 `차량 운행 시간`으로 변경하고 누적 시간을 `00시간 00분` 형식으로 표시
- 싱글플레이 순정 AI 드라이버 이름 2,701개를 한국어 음차로 표시
- AI 이름에 필요한 68개 한글 음절을 일반 UI 폰트 46종에 추가하고 기존 글리프 모양·metrics는 그대로 보존
- AI 능력치·차량·리버리·선택 로직과 멀티플레이 사용자 이름은 변경하지 않음
- v0.6.5 설치 상태에서 업데이트하고 제거하면 설치 직전 v0.6.5 상태로 exact 복원

## 실행

설치 후 생성된 `오모빌2 한글판` 바로가기 또는 게임 폴더의 `AMS2 Korean Launcher.exe`로 실행하십시오. VR은 `오모빌2 한글판 VR모드` 또는 `AMS2 Korean VR Launcher.exe`를 사용하십시오.
