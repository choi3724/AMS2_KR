# AMS2 한국어 패치 Closed Beta 0.6.85

## 변경 사항

- 배너 아래 `패치 검증 / Steam 빌드 / 패치 버전` 상태 카드의 세로 늘어짐을 수정했습니다.
- 원본 상태 카드 이미지(2800×176)의 종횡비를 기준으로 화면 폭과 DPI에 맞춰 높이를 자동 조정합니다.
- 상태 문구, Steam 빌드, 패치 버전의 세로 위치도 카드 높이에 맞춰 함께 조정됩니다.
- 0.6.84의 게임 번역·폰트·동적 `IGPHASEHUD.bff` 최소 패치 payload는 변경하지 않았습니다.

## 배포 정책

- GitHub Release는 Latest이며 Pre-release가 아닙니다.
- 배포 자산은 `AMS2 한국어 패치 CB 0.6.85.zip` 하나만 포함합니다.
- Replay 시간 열 잘림 문제는 이번 버전의 범위가 아닙니다.
