# AMS2 한국어 패치 CB 0.6.83

## 변경 사항

- 사용자가 제공한 배너를 적용한 검정/적색 인스톨러 UI 리디자인
- Pretendard 기반 고해상도 버튼·상태 카드 이미지 적용
- 주 버튼 및 자동 감지/찾기 버튼 글자 확대
- 패치 상태, Steam 빌드, 패치 버전 표시 개선
- 설치 시 canonical stock backup 및 파일 소유권 ledger 기록
- 제거/복구 시 영문 원본 SHA-256 검증 및 패치 생성 파일 완전 제거
- 이전 패치가 만든 소유 바로가기 정리 및 사용자 수정 바로가기 보호
- 혼합 상태, 백업 손상/누락, 수동 변경 상태 구분

## 검증

- 실제 설치 → 검사 → 제거 → 영문 원본 검사 순환 3회 PASS
- 복원 파일 95개 SHA-256 일치
- 패치 생성 파일 355개 잔존 0
- 패치 소유 바로가기 잔존 0
- 최종 게임 상태 `RESTORED_EXACT`

## 알려진 보류 사항

- Replay/Session 시간 열 우측 clipping은 이번 버전에 포함하지 않았습니다.
- 게임 번역·HUD·폰트 payload는 v0.6.82 기준에서 변경하지 않았습니다.

이 릴리즈는 이름에 Closed Beta를 유지하지만 GitHub의 Pre-release 플래그는 사용하지 않으며 Latest 릴리즈로 게시됩니다.
