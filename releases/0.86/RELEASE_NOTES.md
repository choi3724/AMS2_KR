게임 업데이트 후에도 기존 한글패치를 계속 사용할 수 있도록 업데이트 대응 방식을 개선했습니다.

- 게임 빌드 번호나 파일 버전이 달라져도 현재 파일을 먼저 검사하고 필요한 한글 변경을 자동으로 다시 적용합니다.
- 게임 업데이트와 Content Manager가 만든 무관한 변경을 유지합니다.
- 안전하게 적용할 수 없는 부가 표시 항목은 안내 후 생략하며, 핵심 한글 자산이 정상인 경우 한글 모드 실행을 계속할 수 있습니다.
- 일반 및 VR 실행, 설치 화면의 한글 실행에 같은 확인·재적용 정책을 적용했습니다.
- 작업 중 오류가 발생하면 변경 전 상태로 자동 복구하고, 실패 파일과 단계는 진단 로그에 기록합니다.

게임 업데이트로 파일 구조 자체가 달라져 안전한 적용이 불가능한 경우에는 해당 파일을 변경하지 않고 구체적인 원인을 표시합니다.
